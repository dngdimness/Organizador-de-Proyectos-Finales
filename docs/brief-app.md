# 🧠 Contexto de la aplicación

## 🎯 Propósito
Aplicación web educativa para estudiantes de diseño multimedial.

La app está pensada como una herramienta guiar en proyectos finales a los estudiantes.

---

## 🧩 Estado actual del proyecto

El foco está en el desarrollo del sistema interactivo, que incluye:

- lógica de drag and drop
- sistema de gamificación con puntos
- seguimiento del progreso del usuario
- posibilidad de imprimir el estado del seguimiento

---

## ⚙️ Lógica principal

### 🧲 Drag and Drop
- el usuario arrastra o toca (en mobile) componentes para generar su proyecto final

---

### 🎮 Gamificación
- el usuario tiene una barra de puntaje que va llenando

---

### 📊 Seguimiento
- incluye opción de exportar e imprimir el estado

---

## 🎨 Enfoque

La aplicación está orientada a diseño gráfico y digital, no a desarrollo técnico:

- experiencia de usuario
- comunicación
- sistemas visuales
- interacción

---

## 🚫 Restricciones

- evitar soluciones genéricas
- mantener coherencia pedagógica
- no sobrecargar con lógica innecesaria
- priorizar claridad para estudiantes

---

## 🔮 Próximos pasos

- integración de ejemplos reales de marcas
- implementación de links dinámicos por componente
- mejora del sistema de feedback
- optimización de la experiencia mobile
